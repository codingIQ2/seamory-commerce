# 11. 핵심 화면 와이어프레임

## 문서 목적

화면을 꾸미기 전에 정보의 우선순위, 주요 행동, 반응형 변화와 오류 복구 흐름을 검증합니다. 아래 와이어프레임은 4단계 설계 기준이며 최종 비주얼 시안이 아닙니다.

## 표기 규칙

```text
[ 버튼 ]      사용자 행동
< 입력 >      입력·선택 요소
┌──────┐      콘텐츠·컴포넌트 경계
········      반복되는 콘텐츠
! 안내        오류·경고·상태 피드백
```

- 데스크톱 기준 콘텐츠 최대 폭은 1440px, 모바일 기준 검토 폭은 390px입니다.
- 모든 화면은 고객 헤더 또는 관리자 셸 아래에 배치합니다.
- `가격·재고·주문 상태`는 서버 응답을 기준으로 표시합니다.

## 공통 고객 셸

### 데스크톱

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ HUKUPUKU       SHOP        < 상품과 브랜드 검색________________ >  MY  BAG 2│
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│                           페이지 콘텐츠                                    │
│                                                                            │
├────────────────────────────────────────────────────────────────────────────┤
│ ABOUT   이용안내   개인정보처리방침                         © HUKUPUKU      │
└────────────────────────────────────────────────────────────────────────────┘
```

### 모바일

```text
┌──────────────────────────────┐
│ ☰   HUKUPUKU       검색  BAG 2│
├──────────────────────────────┤
│                              │
│         페이지 콘텐츠         │
│                              │
└──────────────────────────────┘
```

- 로고, 검색, 계정, 장바구니는 모든 고객 화면에서 위치를 유지합니다.
- 키보드 순서는 건너뛰기 링크 → 로고 → 주 내비게이션 → 검색 → 계정 → 장바구니 → 본문입니다.

```text

├────────────────────────────────────────────────────────────────────────────┤

│  계절을 건너 남는 소재와 실루엣                     │      이미지         │  │
│  [ 이번 주 셀렉션 보기 → ]                         │                    │  │
│                                                    └────────────────────┘  │

│  │ 상품 이미지 │ │ 상품 이미지 │ │ 상품 이미지 │ │ 상품 이미지 │              │
```

### 모바일 변화

- 히어로는 문구 → 이미지 → 행동 순서의 단일 열로 쌓습니다.
- `JUST IN`은 2열 그리드이며 가로 스와이프를 필수 탐색 방식으로 사용하지 않습니다.
- P0 홈은 대표 큐레이션 1개와 신상품만 제공하고 과도한 배너를 추가하지 않습니다.

## C-03 상품 상세

### 데스크톱

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ [고객 헤더]                                                                 │
├────────────────────────────────────────────────────────────────────────────┤
│  SHOP / OUTER                                                              │
│  ┌──────────────────────┐ ┌──────────────────────┐  ATELIER N              │
│  │                      │ │                      │  Structure Field Jacket  │
│  │      상품 이미지      │ │      상품 이미지      │  198,000원  158,400원    │
│  │                      │ │                      │  20%                     │
│  └──────────────────────┘ └──────────────────────┘                          │
│  ┌──────────────────────┐ ┌──────────────────────┐  COLOR                  │
│  │      상품 이미지      │ │      상품 이미지      │  [BLACK] [SAND]          │
│  └──────────────────────┘ └──────────────────────┘  SIZE                   │
│                                                    [S] [M] [L 품절]         │
│                                                    QUANTITY < 1 －＋ >      │
│                                                    [ BAG에 담기 ]           │
│                                                    배송·교환 안내           │
├────────────────────────────────────────────────────────────────────────────┤
│  DETAILS       여유로운 실루엣 · 코튼 혼방 · 상품 치수                     │
└────────────────────────────────────────────────────────────────────────────┘
```

### 모바일 변화

- 이미지 → 상품 정보 → 가격 → 옵션 → 수량 → 담기 → 상세 정보 순서입니다.
- 구매 버튼을 화면 하단에 고정할 때는 선택 옵션과 총액을 함께 표시하고 콘텐츠를 가리지 않습니다.
- 품절은 색상만으로 표시하지 않고 `품절` 텍스트와 비활성 상태를 함께 사용합니다.

#### 옵션 미선택

```text
! 색상과 사이즈를 선택해 주세요.
  COLOR 영역으로 초점 이동
```

## C-04 장바구니

### 데스크톱

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ BAG                                                                        │
├───────────────────────────────────────────────┬────────────────────────────┤
│ ┌──────────┐ ATELIER N                        │ ORDER SUMMARY              │
│ │  이미지   │ Structure Field Jacket           │ 상품 합계       158,400원  │
│ │          │ BLACK / M                        │ 할인            -39,600원  │
│ └──────────┘ 158,400원  < 1 －＋ >  [삭제]     │ 배송비               0원  │
│                                               │ ─────────────────────────  │
│ ! 가격이 변경된 상품은 이 위치에 안내          │ 예상 결제 금액  158,400원  │
│ ···········································│ [ 주문하기 ]              │
│                                               │ [ 쇼핑 계속 ]              │
└───────────────────────────────────────────────┴────────────────────────────┘
```

### 모바일 변화

- 상품 카드 아래에 주문 요약이 이어지고 `주문하기`를 전체 너비로 표시합니다.
- 빈 장바구니는 `아직 담긴 상품이 없습니다`와 `SHOP 보기`를 표시합니다.
- 재고 부족 행은 삭제하지 않고 가능한 수량과 `수량 수정` 행동을 제공합니다.

```text
│ < 상세 주소______________________ >           │ 최종 결제 금액  207,800원  │
```

- 가격·재고 충돌 시 상단 요약 오류와 문제 상품 근처의 상세 오류를 함께 제공합니다.

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ORDER H240903-8F21                                      [목록으로]          │

├───────────────────────────────────────────────┬────────────────────────────┤
│ ORDER ITEMS                                   │ SHIPPING                   │
│ [이미지] 상품명 / 옵션 / 주문 당시 단가        │ 박** · 010-****-1234        │
│ [이미지] 상품명 / 옵션 / 주문 당시 단가        │ 주소 일부 마스킹             │
│                                               │                            │
│ PAYMENT                                       │ STATUS HISTORY             │
```

- 현재 상태는 색상과 텍스트, 순서로 함께 전달합니다.
- P1 취소는 가능한 상태에서만 보이며 확인 대화상자를 거칩니다.

## 관리자 공통 셸

```text
┌───────────────┬────────────────────────────────────────────────────────────┐
│ HUKUPUKU ADMIN│ 관리자명                         [스토어로 이동] [로그아웃] │
│               ├────────────────────────────────────────────────────────────┤
│ ● 상품·재고    │                                                            │
│ ○ 주문         │                     관리자 콘텐츠                         │
│               │                                                            │
└───────────────┴────────────────────────────────────────────────────────────┘
```

- 767px 이하에서는 사이드바를 메뉴 버튼으로 접되 현재 영역 제목을 유지합니다.
- 위험한 변경은 색상만으로 구분하지 않고 영향 문구와 확인 단계를 제공합니다.

```text
│                                               │ [이미지 업로드 영역]         │
```

## AD-05 관리자 주문 상세

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 주문 H240903-8F21          현재: PAID      < 다음 상태: PREPARING ▼ > [변경]│
├───────────────────────────────────────────────┬────────────────────────────┤
│ ORDER & CUSTOMER                              │ STATUS HISTORY             │
│ 주문 일시 / 고객 식별 정보 / 테스트 결제       │ PENDING → PAID              │
│                                               │ 수행자 · 시각               │
│ ITEMS                                         │                            │
│ 상품 스냅샷 / SKU / 수량 / 주문 당시 단가      │ SHIPPING                   │
│                                               │ 배송지 / 연락처             │
│ TOTALS                                        │                            │
│ 상품 합계 / 할인 / 배송비 / 최종 금액          │                            │
└───────────────────────────────────────────────┴────────────────────────────┘
```

- 허용된 다음 상태만 선택지로 제공합니다.
- 상태 변경 전 주문 번호, 현재 상태, 다음 상태와 고객 영향이 있는지 확인합니다.
- 충돌이 발생하면 서버의 최신 상태를 보여주고 다시 판단하게 합니다.

## 핵심 오버레이

### 장바구니 담기 확인

```text
┌──────────────────────────────┐
│ BAG에 상품을 담았습니다.       │
│ [ 쇼핑 계속 ] [ BAG 보기 ]     │
└──────────────────────────────┘
```

### 주문 상태 변경 확인

```text
┌──────────────────────────────┐
│ 주문 상태를 변경할까요?        │
│ PAID → PREPARING             │
│ 고객 화면에 즉시 반영됩니다.    │
│ [ 취소 ] [ 상태 변경 ]         │
└──────────────────────────────┘
```

## 와이어프레임 검토 결과

| 검토 질문 | 결정 |
| --- | --- |
| 첫 화면에서 핵심 행동이 보이는가? | 홈 `셀렉션 보기`, 상세 `BAG에 담기`, 장바구니 `주문하기`를 한 개의 주 행동으로 유지 |
| 모바일에서 기능이 사라지는가? | 필터는 시트, 관리자 메뉴는 접힘으로 바뀌지만 기능은 유지 |
| 오류 뒤에 복구 행동이 있는가? | 필터 초기화, 수량 수정, 장바구니 복귀, 새로고침을 오류 옆에 제공 |
| 고객과 관리자 상태가 연결되는가? | 동일 주문 상태와 이력을 고객 상세와 관리자 상세에서 다른 밀도로 표현 |
| 중복 주문을 유도하는가? | 체크아웃 제출 중 입력과 버튼을 잠그고 진행 상태를 알림 |

## 5단계 전달 사항

- 고객 셸과 관리자 셸을 별도 레이아웃 경계로 구현할 수 있어야 합니다.
- 상품 목록 URL 상태, 인증 후 복귀 주소, 체크아웃 멱등성 키를 기술 설계에 포함합니다.
- 상품 카드, 금액 요약, 상태 배지, 옵션 선택기, 오류 안내는 재사용 컴포넌트 후보입니다.
