# 04. 성공 지표와 MVP 완료 조건

## 제품 지표

실제 사용자가 없는 포트폴리오 단계에서는 운영 수치를 꾸며내지 않습니다. 대신 분석 이벤트와 측정 방법을 먼저 설계하고, 사용성 테스트에서 나온 수치를 구분해 기록합니다.

| 목표 | 측정 지표 | 이벤트 예시 |
| --- | --- | --- |
| 상품 발견 | 목록→상세 진입률, 검색 결과 없음 비율 | `view_item_list`, `select_item`, `search` |
| 구매 결정 | 상세→장바구니 전환율 | `view_item`, `select_option`, `add_to_cart` |
| 구매 완료 | 결제 시작→주문 완료율 | `begin_checkout`, `purchase` |
| 안정성 | 주문 실패율, 재고 불일치 건수 | 서버 오류·도메인 오류 로그 |
| 품질 | 핵심 흐름 자동화 테스트 성공률 | CI 테스트 결과 |

## MVP 완료 조건

- 비로그인 사용자가 상품을 검색하고 필터링해 상세를 볼 수 있습니다.
- 사용자가 옵션을 선택해 장바구니에 담고 테스트 주문을 완료할 수 있습니다.
- 서버가 주문 시 가격과 재고를 다시 검증합니다.
- 로그인 사용자가 자신의 주문 내역과 상태를 확인할 수 있습니다.
- 관리자가 상품·옵션·재고와 주문 상태를 변경할 수 있습니다.
- 권한이 없는 사용자는 관리자 기능에 접근할 수 없습니다.
- 모바일 360px부터 데스크톱까지 핵심 화면이 깨지지 않습니다.
- 키보드만으로 핵심 구매 흐름을 진행할 수 있습니다.
- 핵심 도메인 로직에 단위 테스트, 구매 흐름에 E2E 테스트가 있습니다.
- 공개 배포 주소, 테스트 계정, 아키텍처 설명, 회고가 README에 정리되어 있습니다.
