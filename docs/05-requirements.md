# 05. 요구사항 명세

## 문서 목적

이 문서는 SEAMORY MVP에서 **무엇을 만들고 무엇을 만들지 않을지**를 고정합니다. 각 요구사항의 ID는 사용자 시나리오, 백로그, 테스트에서 공통으로 사용합니다.

## 우선순위 기준

| 등급 | 의미 |
| --- | --- |
| P0 | MVP 출시와 핵심 구매 흐름에 반드시 필요 |
| P1 | 핵심 흐름을 개선하지만 첫 배포 이후 추가 가능 |
| P2 | 제품 확장 단계에서 검토 |

## 사용자 역할

| 역할 | 설명 |
| --- | --- |
| Guest | 로그인하지 않은 방문자 |
| Member | 로그인한 고객 |
| Admin | 상품·재고·주문을 관리하는 운영자 |

## 데이터와 콘텐츠 원칙

- 상품과 브랜드는 포트폴리오용 가상 데이터만 사용합니다.
- 실제 브랜드의 로고, 상품 이미지, 설명, 리뷰를 무단으로 복제하지 않습니다.
- 사용자 개인정보는 최소한으로 수집하고 데모 데이터와 구분합니다.
- 테스트 계정과 테스트 결제임을 화면과 README에서 명확히 알립니다.

## MVP 제외 범위

- 실제 PG 결제 승인, 정산, 세금계산서
- 다중 판매자 입점과 수수료 정산
- 해외 배송, 다국어, 다중 통화
- 리뷰·커뮤니티·라이브 방송
- 머신러닝 기반 개인 추천
- 복잡한 쿠폰 중복과 회원 등급 정책

## 변경 관리

요구사항을 추가하거나 의미를 바꿀 때는 관련 사용자 시나리오, 도메인 규칙, 백로그, 테스트 계획도 함께 갱신합니다. P0 범위가 늘어나면 기존 P0 항목과 교환할 기능을 먼저 결정해 범위가 계속 커지는 것을 막습니다.
