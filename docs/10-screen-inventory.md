# 10. 화면 목록과 책임

## 문서 목적

각 화면이 해결할 사용자 과업, 주요 정보, 행동, 예외 상태와 연결 요구사항을 정의합니다. 화면 ID는 와이어프레임, 구현 작업, 테스트 이름에서 공통으로 사용합니다.

## 우선순위 기준

- **P0**: 핵심 데모 흐름과 운영에 필요한 MVP 화면
- **P1**: 첫 배포 이후 탐색·계정 경험을 확장하는 화면
- 모달, 토스트, 필터 시트는 독립 페이지가 아니라 소유 화면의 상태로 관리합니다.

## 시스템 화면과 공통 피드백

| ID | 상태 | 표시 원칙 | 사용자의 다음 행동 |
| --- | --- | --- | --- |
| S-01 | 찾을 수 없음 | 존재 여부를 과도하게 노출하지 않는 짧은 설명 | 홈 또는 이전 안전 화면으로 이동 |
| S-02 | 접근 거부 | 권한이 필요함을 설명하되 보호 데이터는 표시하지 않음 | 적절한 계정으로 로그인 또는 스토어 이동 |
| S-03 | 예기치 않은 오류 | 개인정보 없는 오류 추적 ID와 재시도 안내 | 재시도 또는 안전 화면 이동 |
| S-04 | 네트워크 지연 | 기존 콘텐츠를 가능한 한 유지하고 진행 상태 전달 | 기다리기 또는 재시도 |

## 화면별 필수 상태

| 화면군 | 로딩 | 빈 상태 | 사용자 수정 가능 오류 | 시스템·도메인 오류 |
| --- | --- | --- | --- | --- |
| 상품 목록 | 카드 스켈레톤과 결과 영역 상태 | 조건에 맞는 상품 없음, 필터 초기화 | 잘못된 URL 값은 기본값으로 정규화 | 목록 재시도 |
| 상품 상세 | 이미지·구매 정보 자리 유지 | 판매 중단/품절 안내 | 옵션 미선택, 수량 초과 | 상품 조회 재시도 |
| 장바구니 | 금액 갱신 상태 | 쇼핑으로 이동 | 수량 초과, 품절 항목 수정 | 가격·재고 검증 재시도 |
| 인증 | 제출 버튼 진행 상태 | 해당 없음 | 항목 오류, 잘못된 계정 정보 | 잠시 후 재시도 |
| 체크아웃 | 주문 생성 중 중복 제출 차단 | 장바구니로 이동 | 배송지 입력 오류 | 가격 변경·재고 부족·결제 실패 |
| 주문 목록 | 목록 스켈레톤 | 첫 쇼핑 시작 | 해당 없음 | 조회 재시도 |
| 관리자 목록 | 표 또는 카드 스켈레톤 | 등록/필터 초기화 | 필터 값 정정 | 조회 재시도 |
| 관리자 편집 | 저장 진행 상태 | 해당 없음 | 항목별 검증 오류 | 충돌 데이터 새로고침 후 재시도 |

## 핵심 화면 상세 책임

### C-02 상품 목록·검색

- 상단: 제목 또는 검색어, 전체 결과 수
- 도구: 검색, 정렬, 필터 열기, 적용 필터 칩과 전체 초기화
- 본문: 상품 카드 그리드, 페이지 이동
- 모바일: 필터를 전체 높이 시트로 제공하고 적용 전 선택과 적용된 URL 상태를 구분
- 뒤로 가기 시 필터, 페이지, 가능한 범위의 스크롤 위치를 복원

### C-03 상품 상세

- 이미지 갤러리와 브랜드·상품명·가격·할인·소재·배송 정보
- 색상과 사이즈 조합을 하나의 옵션으로 선택
- 품절 옵션은 비활성화와 텍스트를 함께 제공
- 구매 영역은 데스크톱에서 정보 옆, 모바일에서 읽기 흐름 뒤에 배치
- 장바구니 담기 성공 후 `장바구니 보기`와 `쇼핑 계속`을 선택할 수 있게 함

### C-04 장바구니

- 품목별 이미지, 상품명, 옵션, 단가, 수량, 소계와 제거 행동
- 상품 합계, 할인, 배송비, 최종 예상 금액을 구분
- 가격·재고가 바뀐 항목은 자동 삭제하지 않고 이유와 수정 행동 제공
- 주요 행동은 `주문하기`, 보조 행동은 `쇼핑 계속`으로 통일

### O-01 체크아웃

- 배송지, 주문 품목, 최종 금액, 테스트 결제 안내를 한 화면에서 검토
- 서버 검증 전까지 화면 금액을 확정 금액처럼 표현하지 않음
- 주문 제출 후 버튼과 입력을 잠가 중복 요청을 예방
- 재고·가격 충돌 시 주문을 만들지 않고 문제 품목과 장바구니 복귀 행동 제공

### AD-03 상품·재고 수정

- 기본 정보, 가격, 미디어, 판매 상태, 옵션·SKU·재고 영역을 구분
- 재고 조정은 새 재고 값뿐 아니라 변경 사유를 필수로 입력
- 저장 전후 상태와 고객 화면 노출 영향을 명확히 표시
- 상품·옵션은 주문 이력이 있으면 삭제 대신 보관 또는 비활성화

### AD-05 관리자 주문 상세

- 주문 번호, 주문자, 배송 정보, 상품 스냅샷, 금액, 현재 상태, 변경 이력 표시
- 가능한 다음 상태만 행동으로 제공하고 금지된 전환은 서버에서도 거부
- 상태 변경 전 영향과 대상 주문을 확인하고 성공 후 이력을 즉시 갱신

## 반응형 기준

| 구간 | 레이아웃 원칙 |
| --- | --- |
| 360~767px | 단일 열, 터치 영역 최소 44px, 필터 시트, 표는 카드 또는 핵심 열 중심 |
| 768~1199px | 2~3열 상품 그리드, 필요 시 보조 영역 접기 |
| 1200px 이상 | 4열 중심 상품 그리드, 목록 필터와 구매 요약을 나란히 배치 가능 |

브레이크포인트 숫자보다 콘텐츠가 깨지지 않는 시점을 우선하며, 가로 스크롤을 핵심 구매 흐름의 기본 해결책으로 사용하지 않습니다.
